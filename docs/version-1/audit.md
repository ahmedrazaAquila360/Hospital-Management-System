## Workflow tracing

- Reception → patient action → advisory duplicate lock/MRN sequence → appointment service → PostgreSQL overlap constraint → check-in Encounter/token → OPD ClinicalNote → prescription/lab action → invoiceService/manual invoice → Payment/refund. Missing UI regression orchestration and manual billing safeguards prevent marking the whole gate complete.
- Admission action → createAdmission → bed conditional allocation + BedStay + encounter/deposit → changeAdmission transfer → discharge settlement + summary → cleaning. Non-bed daily service posting is a genuine gap. Existing minimum one-day/bed-night convention requires operator confirmation, not silent alteration.
- Lab order → authorized encounter lookup → LabOrder snapshot → sample/processing/result transitions → different verifier → release → LAB-source invoice + notification → scoped printable report. Existing behavior bills on RELEASED, not ORDERED; Guardian must distinguish pending/unbilled orders from realized revenue leakage.
- Prescription → medicine/allergy acknowledgement → dispensing verification → batch guard/expiry → one Dispensing + invoice → payment → return credit/restock + refund. Receipt/adjustment audit does not replace a complete stock movement/purchase ledger.
- Permissions/session → active BranchMembership → scoped Prisma transaction role → SQL RLS + visible-link triggers → per-action guard. Global hospital configuration/catalogs are deliberately shared; operational records remain branch-specific. Base client exceptions are authentication/admin/maintenance and central identity deduplication.
